# Emotion Detection Web Application

## Introduction

This repository contains the final project for the IBM Coursera course **Developing AI Applications with Python and Flask** (Generative AI Engineering Professional Certificate).

The application detects emotions in customer feedback text using the embeddable **Watson NLP** Emotion Predict library and presents the results through a Flask web interface.

## Project Overview

Emotion detection goes beyond simple positive/negative sentiment analysis. Given a text statement, the application returns scores for five emotions and identifies the dominant one:

- Anger  
- Disgust  
- Fear  
- Joy  
- Sadness  
- Dominant emotion
